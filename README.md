# Jakarta House Price Prediction
Tugas Akhir UAS Matematika Sains Data 1

Penerapan *machine learning* untuk memprediksi harga rumah di wilayah Jakarta berdasarkan spesifikasi bangunan, luas tanah, jumlah ruangan, serta lokasi kecamatan (*district*).
